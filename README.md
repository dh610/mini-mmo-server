# mini-mmo-server

<!-- 프로젝트가 끝나갈 때 본인이 쓸 것. 아래는 뼈대만. -->

넓은 2D 맵에 다수 사용자가 접속한 상황에서, **(1) 각자에게 필요한 정보만 골라 보내
브로드캐스트 비용을 줄이고, (2) 동시 요청에서 상태 정합성을 지키는 것**을 다룬 게임 서버.

게임을 만드는 프로젝트가 아니라, **게임 서버가 겪는 문제 두 개를 골라 재현하고 측정한** 프로젝트다.

> C++는 이번이 처음이다. C로 소켓·pthread 기반 게임 서버를 만든 경험을 바탕으로,
> 온라인 게임 서버에서 실제로 문제가 되는 두 지점을 골라 구현하고 측정했다.

## 착안점

메이플스토리의 채널·필드 구조에서 착안했으나, 좌표계는 top-down 2D로 단순화했다.
원작의 사이드뷰 플랫폼 물리는 공간 분할 검증과 무관해 제외했다.
에셋과 상표는 사용하지 않았다.
